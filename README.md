### 👋 Sobre mí

Soy un **desarrollador Full Stack** apasionado por crear experiencias digitales inmersivas.  
Fundador de **Archinime**, una plataforma de streaming de anime con temática cyberpunk.  
Me encanta combinar **código, diseño y animación** para dar vida a proyectos únicos.

- 🔭 **Actualmente trabajando en:** Archinime (160+ animes, chat en tiempo real, sistema de stickers).
- 🌱 **Aprendiendo:** Nuevas tecnologías para mejorar la experiencia de usuario.
- 💬 **Pregúntame sobre:** Firebase, JavaScript, HTML/CSS, o cualquier cosa relacionada con anime.
- ⚡ **Dato curioso:** Mi web tiene efectos visuales de neón y un sistema completo de autenticación.
