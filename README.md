## 🌌 Sobre Archinime

<div align="center">
  <img src="https://cdn.jsdelivr.net/gh/Archinime/Archivos-data@main/Logo_Archinime_animado.gif" alt="Archinime Logo" width="160" style="border-radius: 50%;" />
</div>

**Archinime** es una plataforma de streaming de anime **independiente** con una **interfaz cyberpunk inmersiva**. Combina diseño neón, efectos visuales, comunidad en tiempo real y un catálogo masivo de más de **160 animes** (y creciendo). Todo el sistema está impulsado por una sólida arquitectura de **JavaScript puro + Firebase Cloud Firestore + pasión por el anime**.

### 🎯 ¿Qué me hace especial?

<table>
<tr>
<td width="50%">

**🎨 Diseño y UX**
- 🎮 Efectos visuales (partículas, chroma key, animaciones CSS)
- 🌈 Tema cyberpunk con paleta neón personalizable
- 📱 PWA instalable nativa

</td>
<td width="50%">

**💬 Comunidad**
- 💬 Chat global en tiempo real con stickers
- 🔔 Sistema de notificaciones inteligente
- ⭐ Votaciones y rankings de animes

</td>
</tr>
<tr>
<td width="50%">

**📺 Reproducción**
- 🎬 Reproductor multi-servidor (9+ opciones)
- 📌 Marcador de episodios vistos sincronizado
- 🖼️ Sistema de stickers personalizables (Catbox)

</td>
<td width="50%">

**🔐 Backend**
- 🔐 Autenticación Firebase (correo, Google, GitHub)
- ☁️ Firestore con reglas granulares
- ⚡ Service Worker con versionado inteligente

</td>
</tr>
</table>
