## 🚀 Sobre Mí

Soy un **desarrollador Full Stack** obsesionado con la estética **cyberpunk** y la inmersión digital.  
Fundador de **Archinime**, una plataforma de streaming de anime con identidad visual única, efectos neón, sistema de votaciones, chat en tiempo real y un catálogo de **más de 160 animes**.

Me encanta fusionar **diseño, animación y funcionalidad** para crear experiencias que no solo se usen, sino que se **vivan**.

- 🔭 **Actualmente:** Desarrollando ARCHINIME OS, una interfaz de usuario de próxima generación.
- 🌱 **Aprendiendo:** Nuevas tecnologías para potenciar la experiencia de usuario.
- 💬 **Pregúntame sobre:** Firebase, JavaScript, HTML/CSS, o cualquier cosa relacionada con anime.
- ⚡ **Dato curioso:** Mi web tiene un sistema de **chroma key** con personajes animados en pantalla.
